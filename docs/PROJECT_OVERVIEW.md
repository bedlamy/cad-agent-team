# Паспорт проекта

## Цель

Создать не четыре независимых чата, а устойчивую инженерную команду, которая ведёт CAD-задачу от постановки до проверяемого результата: понимает текущее состояние проекта, при необходимости исследует фактическую геометрию, выполняет изменение, сохраняет ревизии, независимо проверяет результат и возвращает короткий отчёт.

## Технологический стек

- LibreChat `v0.8.9-rc1` — UI, Agents, Subagents, Skills.
- EZ AI — OpenAI-compatible custom endpoint `https://api.ez-ai.ru/v1`.
- FreeCAD — GUI-сессия в Docker; в Skills Pack указан FreeCAD `1.1.4`, в раннем handoff точная версия ещё не была установлена.
- FreeCAD MCP Bridge `v0.1.30` — Python-инструменты в живом процессе FreeCAD.
- Docker network `cad_mcp` — стабильная адресация LibreChat API ↔ FreeCAD.
- `<CAD_WORKSPACE>` — целевой CAD Workspace.
- `<CAD_AGENT_HOME>/bin/cad_revision.py` — helper ревизий, установленный по отчётам.

## Основные принципы

1. Проект непрерывен между сообщениями; не повторять полный анализ неизменённой модели без причины.
2. Источник истины о геометрии — живой документ и проверенные FCStd snapshots, а не текстовое описание агента.
3. Coordinator управляет ходом задачи; специализированные агенты выполняют самостоятельные bounded jobs.
4. Все изменяющие операции одной живой FreeCAD-сессии сериализуются.
5. Для каждой логической мутации предусмотрены before/after snapshots; helper не является принудительным gateway и не гарантирует, что агент вызовет checkpoint.
6. Reviewer проверяет результат независимо, а не принимает заявление Builder.
7. Read-only роли в текущей конфигурации — логические правила, не техническая песочница.
8. Исходные STEP/FCStd не перезаписывать; работать с копией/проектом.

## Не входит в цель

- Автоматически менять Docker/LibreChat/MCP/ACL или FreeCAD preferences.
- Подменять FreeCAD MCP Bridge другим сервером без отдельного исследования.
- Запускать все три subagents на каждый пользовательский вопрос.
- Считать Skills системой прав доступа.
- Считать `project_state.json` абсолютной истиной о живой геометрии.
