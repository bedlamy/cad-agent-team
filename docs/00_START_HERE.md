# Начать здесь — CAD Agent Team

## Что это за проект

CAD Agent Team — команда из четырёх LibreChat Agents, работающих с FreeCAD через FreeCAD MCP Bridge. Coordinator — пользовательская точка входа и оркестратор; Analyst исследует геометрию; Builder создаёт/изменяет CAD; Reviewer независимо проверяет результат.

## Что считать текущей архитектурой

- Исторический baseline v1: один writer — Coordinator; специалисты не имели прямого MCP.
- v2: все четыре агента получили прямой FreeCAD MCP, а Coordinator получил настоящие Subagents-связи. Read-only для Analyst/Reviewer осталось политикой промпта, а не технической изоляцией.
- v3: Coordinator обязан делегировать любые изменения геометрии/CAD-документа Builder; Analyst вызывается для неизвестного/изменившегося/противоречивого состояния; Reviewer — для существенных изменений и контрольных точек. Существующий prompt v3 Coordinator сохранён в `agents/v3/coordinator-v3.md`.
- Skills v0.1: шесть Skills; поздний отчёт 17 Nov 13:22 UTC сообщает, что они были импортированы и назначены, а четыре агента обновлены v3 prompts. См. `docs/SKILLS.md` и конфликт статусов в `docs/DECISIONS_AND_CONFLICTS.md`.

## Что произошло в последнем инциденте

Пользователь дал Coordinator read-only задачу: изучить ZIP, начать с `00_CAD_AGENT_BRIEF.md`, понять конструкцию и визуальные референсы, ничего не моделировать и остановиться с отчётом. Coordinator:

- долго искал архив через FreeCAD filesystem;
- использовал `read_file` с неподходящими путями пять раз;
- извлёк изображения, но не смог их просмотреть;
- не вызвал Analyst, несмотря на незнакомую геометрию и прямое правило v3;
- многократно исследовал сечения STEP, повторял гипотезы и генерировал большие ASCII-карты;
- не закончил отчёт.

Сырой экспорт не публикуется; обезличенная сводка: `docs/incidents/2026-11-17-coordinator-overrun-summary.md`.

**Исправленная статистика по исходному execution trace:** 24 tool calls: 17 `execute_python_mcp_freecad`, 5 неудачных `read_file`, 2 `get_output_page_mcp_freecad`; 0 вызовов Subagent. Предыдущий ответ в чате ошибочно оценил общее количество как 26 и FreeCAD MCP как 19.

## Что делать новому чату

1. Сначала прочитать текущие документы и опубликованные sanitized source packages.
2. Проверить live состояние только read-only: список агентов, точные prompts, Skill IDs/assignments, модели, tools, Subagents, runtime tools, MCP Bridge, workspace permissions, `cad_revision.py`.
3. Сверить live состояние с архивом и отдельно зафиксировать отличия.
4. Не исправлять поведение Coordinator, не менять prompts/Skills/tools и не перезапускать сервисы, пока пользователь не согласует отдельный план.
5. Не реконструировать отсутствующие v3 prompts по SHA-256. Получить точные тексты из live Agent Builder или исходного workspace.

## Статусы

- `CONFIRMED` — прямо подтверждено инструментом/тестом/файлом.
- `REPORTED` — заявлено в отчёте или сообщении, но не перепроверено сейчас.
- `PLANNED` — предложение/план, не считать реализованным.
- `UNKNOWN` — отсутствует достаточное доказательство.
- `CONFLICT` — источники расходятся; хранить оба, не угадывать.
