# Правила работы с репозиторием CAD Agent Team

Этот репозиторий — документация и архив источников проекта CAD Agent Team. Он **не является** подтверждением текущего live-состояния LibreChat, FreeCAD или VM.

## Перед началом любой работы

1. Прочитать `docs/00_START_HERE.md`, `docs/CURRENT_STATE_2026-11-17.md`, `docs/ARCHITECTURE.md`, `docs/AGENTS_AND_PROMPTS.md`, `docs/KNOWN_GAPS.md`.
2. Для инцидента читать исходный экспорт в `docs/incidents/`, а не только краткое резюме.
3. Сохранять происхождение и статус каждого факта: `CONFIRMED`, `REPORTED`, `PLANNED`, `UNKNOWN`, `CONFLICT`.
4. Не выдавать предложение, пакет подготовки или исторический отчёт за применённую конфигурацию.

## Запрещено без отдельного явного разрешения пользователя

- менять live prompts, модели, Skills, tool assignments или Subagents;
- менять MCP Bridge, FreeCAD Preferences, Docker Compose, LibreChat YAML, сеть, TLS, токены, credentials;
- менять ACL/ownership рабочего пространства, перезапускать сервисы или контейнеры;
- выполнять CAD-изменения в пользовательских документах;
- делать платные генерации EZ AI ради диагностики;
- публиковать секреты, `.env`, API keys, Bearer tokens, cookies, private keys, MongoDB backups или реальные учетные данные.

## Техническая безопасность

`execute_python` FreeCAD MCP — произвольный Python внутри живой GUI-сессии. Инструкция роли `read-only` не является sandbox. Bridge в последнем историческом отчёте был в `Unrestricted`; считать это доверенной средой и не запускать код без необходимости.

Операции с одной живой FreeCAD-сессией должны быть последовательными. Не запускать Reviewer параллельно с Builder, когда тот изменяет документ.

## Изменение документации

- Сохранять оригинальные архивы и исторические prompt-файлы неизменными.
- Новые выводы добавлять отдельными датированными документами.
- Не переписывать старый handoff так, будто он всегда содержал более поздние сведения.
- При расхождении добавлять запись в `docs/DECISIONS_AND_CONFLICTS.md` и `docs/CURRENT_STATE_2026-11-17.md`.
