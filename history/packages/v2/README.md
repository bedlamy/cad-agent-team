# CAD Agent Team — architecture v2.0

**Дата:** 2026-11-16 · **Текущая конфигурация:** LibreChat v0.8.9-rc1 / EZ AI / FreeCAD MCP Bridge v0.1.30.  
**Статус:** пакет настройки для существующих четырёх агентов; не подтверждение применения.

## Основная идея

Команда продолжает работу над проектом между сообщениями. Coordinator — руководитель, а не обязательный диспетчер каждой мелкой операции. Специалисты имеют прямой MCP-доступ для своей работы. Analyzer вызывается только при нехватке данных, конфликте фактов или изменении исходного контекста. Reviewer подключается по риску и по контрольным точкам, а не после каждой тривиальной правки.

Работа с FreeCAD может быть автономной: нет обязательного согласования каждой правки, **но автоматически создаются ревизии** до и после каждой законченной изменяющей операции. Источник STEP сохраняется неизменным. При необходимости восстановления открывается предшествующая ревизия.

## Содержимое

- `COMPUTER_TASK.md` — единый установочный план для Computer.
- `ARCHITECTURE.md` — роли, маршрутизация и правила непрерывного проекта.
- `MANIFEST.yaml` — IDs четырёх существующих агентов и целевые toolsets.
- `VERSIONING.md` — инженерная схема ревизий, контрольных точек и состояния проекта.
- `versioning/cad_revision.py` — минимальный helper для `Document.saveCopy()`, журнал ревизий и эвристическая проверка неизменности.
- `versioning/test_revision.py` — автономные тесты helper на имитированном документе (не FreeCAD).
- `agents/*.md` — полные инструкции каждому из четырёх агентов.
- `MODEL_POLICY.md` — выбор моделей и опциональное reasoning.
- `ACCEPTANCE_TESTS.md` — интеграционная приёмка.
- `SOURCES.md` — первичные документы.
- `PACKAGE_SHA256.json` — контрольные суммы.

## Как передать Computer

Отправить **этот ZIP** в workspace `computer-admin` и ровно одно задание:

> Распакуй приложенный архив, прочитай полностью `COMPUTER_TASK.md` и выполни его как технический исполнитель без изменения архитектуры. Применяй изменения к существующим четырём агентам; не создавай новых. Подготовь версионирование и протестируй его на отдельном тестовом документе. Не меняй режим Ask на Unrestricted без моего отдельного явного подтверждения в FreeCAD. Верни один отчёт согласно ACCEPTANCE_TESTS.md.

## Предупреждение о свободном исполнении

Существующий MCP Bridge предоставляет `execute_python`, то есть произвольный Python в процессе FreeCAD. Раздача доступа четырём агентам означает доверие всем четырём: инструкции «только чтение» **не являются технической песочницей**.

Чтобы устранить постоянные окна Allow, Bridge необходимо один раз переключить в `Unrestricted` с пониманием последствий. Установочный пакет **не делает этого автоматически** и не обходит предупреждение. Пока пользователь явно не включил этот режим, Ask продолжит запрашивать подтверждение для каждого Python-вызова.
