# Model policy

Не сменять модели ради самой настройки. В текущей установке ранее использовались `ez-ai / deepseek/deepseek-v4.1-flash` для специалистов и `ez-ai / anthropic/claude-sonnet-5.5` для Coordinator; последняя модель не была независимо подтверждена в каталоге.

Правила:
1. Проверить фактический актуальный каталог EZ AI и настройки существующих агентов.
2. Главному Coordinator — сильную модель, которая действительно доступна и уверенно вызывает Subagents/MCP.
3. Analyst/Builder/Reviewer — недорогую модель, **если она реально умеет MCP tool calling и выполняет роль качественно**. Если Flash не умеет, выбрать подтверждённую модель с инструментами. Не угадывать model IDs.
4. Уровни reasoning не менять без подтверждённой поддержки через endpoint `customParams.reasoningFormat` и модель. Установка reasoning не блокирует CAD.
5. Не делать платные серийные бенчмарки; минимальные функциональные вызовы в рамках приёмки допускаются, с малой длиной.
6. Для сложной инженерной задачи повысить модель Builder/Reviewer или вызвать сильную модель по ситуации, если это нужно для качества, а не всегда.
