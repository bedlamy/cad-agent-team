# Anonymized external CAD audit case study

The 2026-11-17 incident involved a user-supplied CAD archive containing a brief, engineering constraints, a main STEP assembly, an overlay component, a keycap model, reference views, a prototype photograph, and design renders.

The original customer/project files and raw conversation/tool export are intentionally not published. The public incident summary preserves the agent-behavior findings and aggregate execution statistics without exposing customer CAD geometry, file metadata, or local environment details.

The original input archive was not available for public redistribution and was not copied into this repository.
